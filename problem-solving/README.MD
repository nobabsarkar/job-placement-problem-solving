### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

```bash
cd YOUR_REPOSITORY_NAME
```

### 3. View the Solutions

Open `problem-solving/Solution.ts` in your preferred code editor to explore the solutions.
